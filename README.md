## 🌟 Fonctionnalités

- 🔒 **Gestion complète des comptes**
  - Ajoute plusieurs comptes et bascule facilement entre eux.
  - Prise en charge complète de l'authentification Microsoft (OAuth 2.0) et Mojang (Yggdrasil).
  - Les identifiants ne sont jamais stockés et sont transmis directement à Mojang.

- 📂 **Gestion efficace des assets**
  - Reçois les mises à jour client dès leur sortie.
  - Les fichiers sont vérifiés avant le lancement. Les fichiers corrompus ou incorrects seront retéléchargés.

- ☕ **Validation automatique de Java**
  - Si une version incompatible de Java est installée, nous installerons la bonne version pour toi.
  - Pas besoin d'avoir Java installé pour exécuter le launcher.

- 📰 **Flux d'actualités intégré**
- ⚙️ **Gestion intuitive des paramètres**, y compris un panneau de contrôle Java.
- **Supporte tous nos serveurs**
  - Change facilement de configuration de serveur.
  - Consulte le nombre de joueurs connectés sur le serveur sélectionné.

- **Mises à jour automatiques**. Le launcher se met à jour tout seul.

- **Voir le statut des services Mojang**.

Cette liste n'est pas exhaustive. Télécharge et installe le launcher pour découvrir tout ce qu'il peut faire !
